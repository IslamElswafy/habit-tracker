# 🎯 متتبع العادات - Habit Tracker

تطبيق ويب شامل لتتبع العادات اليومية مع نظام نقاط، تقارير تفصيلية، ومهام فرعية.

## ✨ المميزات

- ✅ **تتبع العادات اليومية** مع نظام checkbox سهل
- ✅ **6 فئات** (دينية، رياضية، تعليمية، صحية، اجتماعية، ترفيهية)
- ✅ **نظام نقاط** قابل للتخصيص (1-100)
- ✅ **مهام فرعية** لتقسيم العادات الكبيرة
- ✅ **Streaks** (الأيام المتتالية) مع 8 مستويات تحفيزية
- ✅ **تقارير أسبوعية وشهرية** مع رسوم بيانية تفاعلية
- ✅ **Drag & Drop** لإعادة ترتيب العادات
- ✅ **مزامنة سحابية** عبر Firebase Firestore
- ✅ **واجهة عربية** كاملة مع دعم RTL
- ✅ **Responsive** - يعمل على جميع الأجهزة

## 🚀 البدء السريع

### 1. التثبيت

\`\`\`bash
npm install
\`\`\`

### 2. إعداد Firebase

1. أنشئ مشروع على [Firebase Console](https://console.firebase.google.com)
2. فعّل Firestore Database
3. انسخ معلومات التكوين إلى `src/config/firebase.js`

### 3. التشغيل

\`\`\`bash
npm run dev
\`\`\`

افتح [http://localhost:5173](http://localhost:5173)

## 📦 السكريبتات المتاحة

\`\`\`bash

## 🎯 الميزات الرئيسية

### المهام الفرعية
قسّم العادات الكبيرة لمهام صغيرة:
- كل مهمة لها نقاطها الخاصة
- تتبع دقيق للتقدم
- مرونة في الإكمال

### نظام Streaks
8 مستويات تحفيزية:
- 🎯 مبتدئ (1-2 يوم)
- 💪 قوي (3-6 أيام)
- 🔥 متحمس (7-13 يوم)
- 🌟 نجم (14-20 يوم)
- ⭐ متألق (21-29 يوم)
- 🏆 بطل (30-99 يوم)
- 💎 ماسي (100-364 يوم)
- 👑 أسطورة (365+ يوم)

### التقارير
- تقارير أسبوعية (7 أيام)
- تقارير شهرية (30 يوم)
- رسوم بيانية تفاعلية
- أفضل العادات والـ Streaks
